## Goal
The command-line tools that turn adapters into data: the scrape runner, the Project Hammer importer, and the merge step that produces `data/prices.json` for the live server.

## Contract
- `scrapers/run.ts` (`npm run scrape`), `scrapers/import-hammer.ts` (`npm run import:hammer`), `scrapers/merge.ts` (`npm run merge:data`), plus `scrapers/lib/week.ts` (`mondayOf(date: Date): string`) and `scrapers/lib/io.ts` (JSON read/write helpers that create directories).
- Uses: `ADAPTERS` from `./adapters` (frozen), `createContext`/`closeBrowser` from `./http` and `./browser`, `matchProduct`/`rankItems` from `./match`, `parseSize`/`parseMultiBuy`/`parsePrice` from `./parse`, `SEED_ITEMS`/`ITEMS` from `../shared/seed/items`, `LOCATIONS` from `../shared/seed/locations`, `generateSeedStore`/`mergeStores` from `../shared/verdict`. All contracts in CONTEXT. Use relative imports (these run under `tsx`).

## run.ts
- Flags: `--retailer <id>` (repeatable; default all enabled in `SCRAPE_CONFIG`), `--item <itemId>` (repeatable; default all items), `--branches primary|all` (default primary), `--cache` (reuse today's raw responses), `--dry` (no writes), `--headed`.
- For each retailer (sequentially) and each item: `adapter.search(item.searchQuery, ctx, branchRef)` → `matchProduct(item, products, previousSizes)` (previousSizes = distinct sizes for that item in `data/prices.json` if present, else `[item.sizeQty]`). Convert a match into a `PricePoint`: `source: "scrape"`, `date: mondayOf(now)`, `sizeQty` from `parseSize(product.sizeText)` (fallback item size), `price`, `regularPrice` (regular ?? was ?? price), `onSale` (explicit flag, or `wasPrice > price`), `wasPrice`, `multiBuy` from `parseMultiBuy`. Per-lb produce: convert to per kg.
- Branches: the primary branch for a retailer is the first location of that retailer in `LOCATIONS` that has `scrapeStoreId` (or none: chain/default price). Its results are chain-level points (no `storeId`). With `--branches all`, every other location with a `scrapeStoreId` is scraped too, producing points with `storeId` = our location id.
- On `BlockedError`: log it, mark the retailer blocked, skip its remaining items.
- Outputs: raw responses via the context cache in `data/raw/<retailerId>/<YYYY-MM-DD>/`; normalised points appended/replaced in `data/scraped/<YYYY-MM-DD>.json`; `data/status.json` (`DataStatus` with `mode: "live"`, `updatedAt`, `sources`, and per retailer `ok`, `lastScrapedAt`, `itemsFound`, `message`).
- Print a summary table: retailer, status, matched/total items, branches, duration; and a list of unmatched items with the best rejected candidate and reason.
- Always `closeBrowser()` at the end.

## import-hammer.ts
- Input CSVs downloaded by the user into `data/hammer/` from https://jacobfilipp.com/hammer/ (a product file and a raw price file). Detect files by name pattern and **read column names from the headers**; don't assume positions. Print a helpful message and exit 0 if files are missing.
- Stream large files line by line (they can be hundreds of MB); handle quoted CSV fields.
- Map vendors (case-insensitive contains): "save-on" → saveon, "no frills"/"nofrills" → nofrills, "walmart" → walmart, "t&t"/"tnt" → tnt. Ignore others.
- Match vendor products to our items with `matchProduct` (map Hammer fields into `RawProduct`). Bucket observations into Monday weeks, keep the last observation per item/store/week; `current_price` → price, `old_price` → wasPrice with `onSale: true`.
- Keep only the latest 26 weeks present in the data. Output `data/hammer-points.json` (`PricePoint[]`, `source: "hammer"`, chain-level).
- Print coverage (items × stores with ≥ 8 weeks) and the date of the newest observation; if it's older than about 60 days, warn that the dataset looks stale.

## merge.ts
- `data/prices.json` = `mergeStores(generateSeedStore(), [hammerPoints (if file exists), ...each data/scraped/*.json oldest first])`.
- Update `data/status.json` `sources` (always "seed", plus "hammer"/"scrape" when present) and `updatedAt`.
- Sanity check: for every item, `getItemDetail` must not throw (import from `../shared/verdict`); report any failures.
