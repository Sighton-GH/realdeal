## Goal
Form inputs that feel chunky and friendly.

## Contract
- `TextField(props: { label; value; onChange(v: string); placeholder?; inputMode?: "text" | "decimal" | "numeric"; prefix?; suffix?; error?; className? })`
- `SearchField(props: { value; onChange(v); onSubmit?(); placeholder?; autoFocus?; className? })`
- `Stepper(props: { value: number; min; max; onChange(v: number); label; className? })`
- `Toggle(props: { checked; onChange(v: boolean); label; description?; className? })`

## Requirements
**TextField**: label above in Nunito 800 small, linked with `useId`. Field `h-14 rounded-sm bg-sunken border-2 border-transparent`, focus-within: `border-grape-400 bg-canvas`. Input Nunito 700 body. `prefix`/`suffix` inside the field in ink-soft. `error`: `border-high`, message below in small `text-high-lip` with a `WarningCircle` (fill) icon; `aria-invalid` and `aria-describedby`.

**SearchField**: `h-14 rounded-md`, 2px `line` border, `bg-sunken`, focus as above. `MagnifyingGlass` icon left, a clear button (`X`, IconButton plain size 40, label "Clear search") on the right when non-empty, Enter calls `onSubmit`. `aria-label` = placeholder. Hide the browser's native search clear button.

**Stepper**: `Minus`/`Plus` raised IconButtons (size 40) around a Fredoka 700 h2 number; disabled at limits; group `aria-label`.

**Toggle**: whole row is a `button role="switch"` with label (Nunito 800) and optional description (small ink-soft) on the left; switch on the right: 52x32 track (`bg-line-strong` off, `bg-grape-500` on), 24px white knob with a 2px darker bottom edge, springs across with `spring.press`.

## Acceptance
- [ ] All inputs are keyboard accessible with visible focus.
- [ ] Error state is clear and announced.
