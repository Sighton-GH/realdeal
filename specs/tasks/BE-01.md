## parse.ts
- `parseSize`: "454 g", "454g", "0.454 kg", "4 L", "4L", "500 mL", "500ml", "12 pack", "12 x 1", "6 pk", "dozen", "12 eggs" (→ dozen 1), "per kg", "/kg", "per lb", "/lb" (lb → kg ×0.4536, returns qty 1 kg for per-weight produce), "1.36 kg", "3 lb bag" (→ 1.36 kg), "650 g" etc. Returns our units: kg, L, each, dozen.
- `parseMultiBuy`: "2 for $5", "2/$5.00", "2 FOR 5.00", "Buy 2 for $5", "2 @ $5" → `{ qty, total }`; null otherwise.
- `parsePrice`: "$5.99", "5.99", "$5", "5,99", "$1.29/lb" → `{ price: 1.29, per: "lb" }`, "$2.84/kg", "$0.99/100g", "$1.49 ea". Ignores text around the price.

## match.ts
- Normalise: lowercase, strip punctuation, drop filler words (the, fresh, organic is NOT dropped), singularise simple plurals.
- Score = token overlap between the product title (+ brand) and the item's name + aliases, + bonus for category words, − penalty for strong mismatch words (e.g. "chocolate" for milk, "unsalted" for salted butter, "whole wheat" for all-purpose).
- Size rule: the parsed product size must be within ±15% of `item.sizeQty` **or** of any `previousSizes` entry (so a shrunk package still matches). Per-kg produce: accept per-kg or per-lb pricing (convert lb price to kg in a `normalisedPrice` field on the reason, not by mutating the product).
- Threshold: return null below a sensible score; `reason` explains the decision ("tokens 3/3, size 454g ok").
- `rankItems`: score free text (e.g. "SALTED BUTTER 454G") against all items; size used as a tiebreaker.

## http.ts
- Per-retailer queue: one request at a time, at least `delayMs` apart (default from config).
- `fetch` with a 20s timeout (AbortController), 1 retry on network errors or 5xx after 5s.
- Block detection → throw `BlockedError`: status 403 or 429, or HTML containing common challenge markers ("captcha", "are you a robot", "access denied", "cf-chl", "px-captcha", "perimeterx", "datadome").
- Cache: when `cacheDir` is set, store responses at `<cacheDir>/<sha1(url+body)>.json` with status and text; when `useCache` is true and a cached file exists, return it with `fromCache: true` and skip the delay.
- Ordinary headers only: a current desktop Chrome `User-Agent`, `Accept`, `Accept-Language: en-CA,en;q=0.9`.
- `newPage()`: opens a page in a per-retailer browser context (from `getBrowser`), viewport 1366×900, locale en-CA, timezone America/Vancouver. Pages are closed by `close()`.
