## Goal
Read a photographed shelf tag or flyer with Gemini and turn it into a `ScanResult` matched to our catalogue.

## Contract
- `server/scan.ts`: `export interface ScanImageInput { data: Buffer; mimeType: string }`, `export async function scanWithGemini(image: ScanImageInput | null, sampleId: string | undefined, store: PriceStore): Promise<ScanResult>`.
- Also return `server/scan.test.ts` (vitest) for the post-processing (mock the Gemini call).
- Uses `@google/genai`, and from `../scrapers/parse` (`parseSize`, `parseMultiBuy`, `parsePrice`) and `../scrapers/match` (`rankItems`); contracts in CONTEXT. Relative imports only.

## Behaviour
- **Samples** (no Gemini needed): `sample-butter` → butter, saveon, price 5.99, wasPrice 8.49; `sample-yogurt` → greek-yogurt-plain, walmart, 5.97, sizeQty 0.5; `sample-pasta` → spaghetti-900g, tnt, multiBuy 2 for 5.00. `candidates`: matched item then 2 more from the same category. `status: "ok"`.
- **No image and no sample** → `{ status: "error", message: "No photo received." }`.
- **No `GEMINI_API_KEY`** → `{ status: "error", message: "Scanning isn't set up on this server." }`.
- **Gemini call**: `new GoogleGenAI({ apiKey })`, model `process.env.GEMINI_MODEL` (default `"gemini-2.5-flash"`; the newest Flash model in AI Studio is fine). Send the image inline (base64 + mimeType) with a JSON response schema for: `isPriceTag` (boolean), `productName`, `brand`, `sizeText`, `price` (number), `wasPrice` (number), `multiBuyText`, `unitPriceText`, `storeName`, `confidence` (0–1), `rawText`. Nullable fields allowed. Temperature 0.
- Prompt: "You are reading a grocery shelf tag or flyer photographed in a Canadian store. Extract only what is printed. If several prices appear, `price` is what the shopper pays now for one unit; a struck-out, 'was', or 'reg.' price goes in `wasPrice`; a multi-buy like '2 for $5' goes in `multiBuyText`. Use null for anything not visible. Do not guess."
- Timeout 15s (AbortController or SDK option). On API failure → `{ status: "error", message: "Couldn't read that photo right now." }` (log the real error server-side without the key).
- **Post-processing** (pure, exported as `postProcess(raw, store)` for tests): `isPriceTag === false` or no price → `no_price` (still include candidates if a product was read). Parse `sizeText` (→ `sizeQty` in the matched item's unit, only if it differs from the item size by > 2%), `multiBuyText` → `multiBuy`. Map `storeName` to a RetailerId by case-insensitive contains ("save-on" → saveon, "no frills" → nofrills, "walmart" → walmart, "t&t" → tnt). `candidates = rankItems(store.items, productName + brand, sizeText, 3)`; empty → `no_price` with message "Penny read the tag but couldn't match the product."

## Tests
`postProcess` with: a clean butter sale tag, a multi-buy pasta tag, a non-price photo (`isPriceTag: false`), a tag with an unknown product, and a per-lb produce tag.
