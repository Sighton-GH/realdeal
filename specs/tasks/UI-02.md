## Goal
Surfaces and small labels: cards, chips, verdict badges, and section headers.

## Contract
- `Card(props: { children; interactive?; tone?: "default" | "sunken" | VerdictTier; onClick?; as?: "div" | "button" | "li"; className? })`
- `Chip(props: { children; selected?; icon?; onClick?; className? })`
- `VerdictBadge(props: { tier: VerdictTier; size?: "sm" | "md"; className? })`
- `Section(props: { title: string; action?; children; className? })`

## Requirements
**Card**: `.lifted rounded-md bg-canvas p-4`. `tone="sunken"`: `bg-sunken`, no border. Verdict tones: tier tint background, tier face colour as the 2px border, tier lip colour as the 4px bottom border. `interactive` (or `as="button"`): renders a `button`, presses 2px (translate-y 2px and bottom border shrinks to 2px) with full keyboard focus.

**Chip**: height 40, `rounded-full`, 2px `line` border, Nunito 800 small, horizontal padding 16. Selected: `bg-grape-50 border-grape-500 text-grape-500`. If `icon` is a Phosphor element, the caller passes the weight; you only colour it. `aria-pressed`.

**VerdictBadge**: pill with tier tint background, `tierMeta[tier].icon` in the tier face colour (fill weight), `shortLabel` in Nunito 800, text colour `tierMeta[tier].textClass`. sm: h-7 micro; md: h-9 small.

**Section**: row with Fredoka 600 `text-h2` title on the left and optional action on the right (actions are usually ghost text buttons: Nunito 800 small grape-500, sentence case, no arrow glyph), children below with a 12px gap.

## Acceptance
- [ ] Cards and chips match DESIGN (lifted surfaces, no blurred shadow).
- [ ] VerdictBadge readable in all 4 tiers (normal tier text is dark, not white).
