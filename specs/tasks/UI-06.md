## Goal
The expressive pieces: Penny's speech bubble, the Kahoot-style store tiles, and empty states.

## Contract
- `SpeechBubble(props: { children; tail?: "left" | "bottom"; className? })`
- `StoreTile(props: { retailer: Retailer; selected?; onClick?; size?: "md" | "lg"; className? })`, plus exported `tileClass: Record<TileColour, string>`
- `EmptyState(props: { mood: PennyMood; title; body?; action?; className? })`

## Requirements
**SpeechBubble**: `bg-canvas`, 2px `line` border, `rounded-md`, Nunito 700 body, padding 12/16. Tail: a 12px square rotated 45° with matching border on two sides, positioned at the left-middle (`tail="left"`, default) or bottom-left (`tail="bottom"`), so the bubble reads as coming from Penny beside or below it.

**StoreTile** (the Kahoot answer tile)
- Face/lip from `tileClass[retailer.tile]` (e.g. `bg-tangerine [--lip:var(--color-tangerine-lip)]`), `.press`, `rounded-md`. lg: min height 96, 6px lip (`box-shadow: 0 6px 0 var(--lip)` override), store `shortName` in white Fredoka 600 22px. md: min height 72, 4px lip, 18px.
- Name sits bottom-left. Top-right: an original geometric glyph per tile colour at 30% white, 28px (lg) / 22px (md): tangerine = rounded 5-point star, pink = half circle, teal = hexagon, violet = squircle. Draw as inline SVG. Do **not** use Kahoot's triangle/diamond/circle/square set.
- Selected: 4px inset white ring and a `CheckCircle` (fill, white) replacing the glyph. `aria-pressed`.
- Dimming of unselected tiles is the parent's job (it passes `className="opacity-60"`).

**EmptyState**: centred column, `<Penny mood size={120} />`, Fredoka 600 h2 title, optional small ink-soft body (`max-w-[36ch]`), optional action below. Vertical padding 40px.

## Acceptance
- [ ] Four store tiles side by side read as a playful game board with four different glyphs.
- [ ] White text on tiles is bold and at least 18px.
