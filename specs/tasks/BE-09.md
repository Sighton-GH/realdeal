## Goal
Optional Tiger Data (TimescaleDB on Postgres) mirror of the price history, with a continuous aggregate for 90-day stats. The app must behave identically without it.

## Contract
- `server/tiger.ts`: `export const tigerEnabled = (): boolean`, `export async function syncToTiger(store: PriceStore): Promise<void>` (never throws), `export async function getTigerStats(itemId: string): Promise<{ avgUnit90: number; lowUnit90: number; highUnit90: number } | null>` (null on any problem).
- Uses `pg` (`Pool`), `unitPriceOf` from `../shared/verdict`. Relative imports.

## Behaviour
- Everything no-ops (returns immediately / null) when `DATABASE_URL` is unset.
- Pool with `ssl: { rejectUnauthorized: false }` when the URL contains `sslmode=require` or the host isn't localhost; max 5 connections.
- Schema (idempotent, run once per process):
  - `price_points(item_id text, retailer_id text, store_id text, week date, price numeric, regular_price numeric, on_sale boolean, was_price numeric, multi_qty int, multi_total numeric, size_qty numeric, unit_price numeric, source text)`.
  - `SELECT create_hypertable('price_points', 'week', if_not_exists => TRUE);`
  - Unique index on `(item_id, retailer_id, coalesce(store_id, 'chain'), week)`.
  - Continuous aggregate `weekly_unit_price` WITH (timescaledb.continuous): `time_bucket('7 days', week)`, item_id, retailer_id, `avg(unit_price)`, `min(unit_price)`, `max(unit_price)`, over rows where `store_id IS NULL`. Add a refresh policy if supported; also call `CALL refresh_continuous_aggregate('weekly_unit_price', NULL, NULL)` after each sync.
- `syncToTiger`: upsert all points in batches of 500 (`INSERT ... ON CONFLICT DO UPDATE`), computing `unit_price` with `unitPriceOf`. Serialise syncs (if one is running, queue at most one more). Log counts and duration.
- `getTigerStats(itemId)`: the engine's definition is "the latest 13 weekly chain points per retailer, then mean/min/max of their unit prices across all retailers". Reproduce that with a window query over `price_points` (rank weeks per retailer descending, keep rank ≤ 13) or over the aggregate, so results match the engine to the cent.
- Wrap every DB call in try/catch; log once per error type, never crash the server.

## Acceptance

- [ ] Without `DATABASE_URL`: zero side effects.
