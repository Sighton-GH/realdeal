## Goal
Penny's voice: the server route that turns her verdict line into speech with ElevenLabs, and the "Hear Penny" button.

## Contract
- `server/routes/speak.ts`: `export const speakRoute: Hono` (mounted at `/api/speak` by BE-07), handling `POST /` with JSON `{ text: string }`.
- `src/components/domain/SpeakButton.tsx`: `export function SpeakButton(props: { text: string; className?: string })`.

## Server
- Validate `text` (1–200 chars) → 400 otherwise.
- Not configured (`ELEVENLABS_API_KEY` or `ELEVENLABS_VOICE_ID` missing) → 501 `{ error: "Voice isn't set up on this server." }`.
- Cache: `data/tts-cache/<sha256(voiceId + text)>.mp3`; serve from cache when present.
- Call ElevenLabs text-to-speech over plain `fetch`: `POST https://api.elevenlabs.io/v1/text-to-speech/{voiceId}` with header `xi-api-key`, JSON `{ text, model_id: "eleven_multilingual_v2" (or the current recommended model), voice_settings: { stability: 0.4, similarity_boost: 0.8, style: 0.35 } }`, `Accept: audio/mpeg`. Check the current ElevenLabs API docs for the endpoint and model id before relying on these.
- Return `audio/mpeg` with `Cache-Control: public, max-age=86400`. Upstream failure → 502 `{ error: "Voice service failed." }`. Never log or return the key.

## SpeakButton
- Render `null` unless `import.meta.env.VITE_VOICE === "on"` and `API_MODE === "live"` (from `@/api/client`).
- Small pill button styled like a secondary button at reduced size (`h-10 px-4`, Nunito 800 small, sentence case: this is a pill, not a 3D CTA): `SpeakerHigh` icon + "Hear Penny". Loading: three-dot indicator. Playing: icon `SpeakerSimpleHigh` with a gentle scale pulse (static under reduced motion) and label "Playing"; tap again stops.
- Fetch once per `text`; keep the object URL for replays; revoke on unmount or text change.
- Respect `soundOn` from the store: when off, disabled with `title="Sound is off"`.
- On error: hide the button and `useToast().show({ message: "Penny lost her voice. The verdict is still right there." })`.
