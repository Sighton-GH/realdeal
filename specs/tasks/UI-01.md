## Goal
The tactile Duolingo-style buttons used on every screen. They must physically press down and feel great.

## Contract (keep exactly; other tasks already import these)
- `Button`, `ButtonProps`, `ButtonVisualProps`, `ButtonVariant`, `buttonClass(visual)`, `buttonVariantClass` from `Button.tsx`
- `LinkButton(props: ButtonVisualProps & { to: string; children })`
- `IconButton(props: { icon; label; variant?: "plain" | "raised"; size?: 40 | 48; onClick?; className?; disabled? })`

## Requirements
**Button**
- Fredoka 600, uppercase, `tracking-[0.04em]`; lg = `h-14 text-[17px]`, md = `h-12 text-[15px]`; `rounded-md`, `px-5`.
- `.press` lip with these face/lip pairs: primary grape-500/grape-700 white text; secondary canvas face, 2px `line` border, `line-strong` lip, grape-500 text; ghost has no face or lip, grape-500 text, `bg-sunken` on hover; verdict variants (steal/good/normal/high) use the tier face/lip and `tierMeta[tier].textOnFaceClass` (normal = ink text).
- `loading`: three dots bouncing in sequence (motion, 600ms loop, each dot 6px, current text colour), keeps the button's width (render the label invisibly underneath), sets `aria-busy`, disables.
- `leftIcon` 22px with a 10px gap.
- Disabled: `bg-sunken text-ink-soft`, `line-strong` lip, no press, `cursor-not-allowed`.
- Calls `play("tap")` on press. Default `type="button"`.
- Reduced motion: dots fade in sequence instead of bouncing.

**LinkButton**: identical visuals, renders react-router `Link`; supports `leftIcon`.

**IconButton**: always circular, `aria-label` and `title` = `label`. `plain`: transparent, ink-soft icon, `bg-sunken` circle on hover. `raised`: canvas face, 2px line border, `.press` lip. Disabled at 40% opacity, no press.

## Acceptance
- [ ] Every variant presses down 4px and loses its lip on `:active`; keyboard focus ring visible.
- [ ] Loading keeps width and is announced; disabled looks disabled.
- [ ] No blurred shadows, gradients, or emoji.
