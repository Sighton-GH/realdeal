## Goal
The live backend: a Hono server that serves the same `Api` as the mock over HTTP using the shared engine and merged real data, plus the browser client for it. One port serves both the API and the built frontend so it can sit behind a Cloudflare tunnel.

## Contract
- `server/index.ts` (entry, `npm run server`), `server/data.ts`, `server/routes/api.ts`, `server/static.ts`, `server/README.md`, and `src/api/live.ts` (`export const liveApi: Api`).
- Uses (contracts in CONTEXT, don't return these files): `scanWithGemini(image | null, sampleId, store)` from `./scan` (BE-08), `syncToTiger(store)`, `getTigerStats(itemId)`, `tigerEnabled()` from `./tiger` (BE-09), `speakRoute` (a Hono app) from `./routes/speak` (BE-10), and engine functions from `../shared/verdict`, `getFeaturedDeals` from `../shared/seed/featured`, `TRICKS` from `../shared/content/tricks`. ## server/data.ts
- `export function getStore(): PriceStore` and `export function startDataWatcher(): void`.
- On start: load `data/prices.json` if it exists (validate it has `items`, `points`, `locations`), else `generateSeedStore()`. Watch the file (`fs.watch` on the directory, 500ms debounce) and reload on change; log reloads. After each load, call `syncToTiger(store)` (fire and forget).

## Routes (`server/routes/api.ts`, mounted at `/api`)
| Method + path | Behaviour |
|---|---|
| GET `/items?q=&category=` | `searchItems` |
| GET `/items/:id` | `getItemDetail`; 404 `{ error: "Item not found" }`. If `tigerEnabled()`, replace `stats.avgUnit90/lowUnit90/highUnit90` with `getTigerStats(id)` when non-null; if they differ from the engine by more than $0.01, log a warning and keep the engine's numbers |
| GET `/items/:id/nearby?lat=&lng=&limit=` | `getNearbyPrices`; validate numbers (400 on bad input); limit 1–20, default 8 |
| GET `/featured` | `getFeaturedDeals(store)` |
| POST `/check` | JSON `PriceCheckInput`; validate known item and retailer, price 0 < p ≤ 1000, optional fields types; 400 with a clear message otherwise; returns `Verdict` |
| POST `/scan` | multipart: optional `image` file (≤ 8 MB, image/*), optional `sampleId`; → `scanWithGemini`; 413/415 on bad uploads |
| GET `/tricks` | `TRICKS` |
| GET `/status` | `data/status.json` if present, else built from the store (`mode: "live"`, sources from the point sources present) |
| POST `/scrape` | header `x-admin-token` must equal `ADMIN_TOKEN` (401 otherwise); spawn `npm run scrape && npm run merge:data` detached; 202; 409 if a run is active |
| `/speak` | `app.route("/speak", speakRoute)` |
- Errors are JSON `{ error: string }` with proper codes; unexpected errors → 500 without stack traces.
- One log line per request: method, path, status, ms.

## server/static.ts and index.ts
- Serve `dist/` for non-`/api` paths with SPA fallback to `dist/index.html`. `Cache-Control: no-cache` for index.html, `public, max-age=31536000, immutable` for `/assets/*`. If `dist/` is missing, respond with a short HTML page saying to run `npm run build`.
- `index.ts`: load `.env` (`process.loadEnvFile?.()` in try/catch), start the data watcher, mount routes, `serve({ fetch: app.fetch, port: Number(process.env.PORT ?? 8788) })`, log the URL and the data source.

## src/api/live.ts
- `fetch("/api/...")` for every `Api` method; JSON in/out; throws `Error(body.error ?? "Request failed")` on non-2xx.
- 15s timeout via `AbortController` (25s for scan).
- `scanImage(image, sampleId)`: `FormData` with `image` (as `scan.jpg`) when present and `sampleId` when present.
- `getNearbyPrices`: query string with lat, lng, limit.

## server/README.md
How to run live mode: copy `.env.example` to `.env` and fill keys; set `VITE_API_MODE=live`; `npm run start`; expose with `cloudflared tunnel --url http://localhost:8788` (HTTPS is required for the phone camera and location); optional `curl -X POST -H "x-admin-token: …" https://<host>/api/scrape`.
