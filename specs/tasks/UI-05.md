## Goal
The bottom sheet and toasts.

## Contract
- `Sheet(props: { open; onClose(); title?; children })`
- `ToastProvider({ children })`, `useToast(): { show(opts: { message: string; tone?: "brand" | VerdictTier }) }`, `ToastOptions`

## Requirements
**Sheet**
- Portal into the element with id `app-column` (see AppColumn in CONTEXT) so on desktop it stays inside the phone column; fall back to `document.body`. Position `absolute inset-0` inside the column (the column is `relative overflow-hidden`).
- Backdrop `bg-ink/55` (no blur) fades in. Sheet `rounded-t-lg bg-canvas`, max-height 85% of the column, scrolls internally, 20px padding, safe-area bottom padding.
- Grab handle (48x6, `bg-line-strong`, rounded). Optional Fredoka 600 h2 title.
- Slides up with `spring.sheet` (AnimatePresence for exit). Closes on backdrop click, Escape, or drag down more than 100px (motion `drag="y"` with constraints).
- Focus moves into the sheet on open, is trapped while open, and returns to the previously focused element on close. `role="dialog" aria-modal="true"`, labelled by the title.
- Reduced motion: fade only.

**Toast**
- Rendered inside the column, just below the top bar (top 68px), centred.
- Pill: `.lifted bg-canvas rounded-full`, padding 12/20, tone icon on the left (brand: `Info`, steal: `Lightning`, good: `ThumbsUp`, normal: `Equals`, high: `WarningCircle`, coloured by tone), Nunito 800 message.
- Pops in with `spring.pop`, auto-dismisses after 2.8s, new toasts replace the current one. `role="status"`.

## Acceptance
- [ ] On a 1280px screen the sheet is contained within the 460px column.
- [ ] Focus trap and Escape work; drag-to-close works on touch.
