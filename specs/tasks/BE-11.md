## Goal
Generate the app's six sound effects with the ElevenLabs sound-effects API (one-time script), so the app has sound with no key at runtime.

## Contract
- `scripts/gen-sfx.ts` (run with `npx tsx scripts/gen-sfx.ts`), writing `public/sfx/{tap,pop,drumroll,slam,chaching,buzzer}.mp3`.
- `src/lib/sfx.ts` already plays `/sfx/<name>.mp3` by name; don't change it.
- This task needs an agent that can run code with an `ELEVENLABS_API_KEY`. A chat-only model should return the script only and say so in NOTES; the integrator runs it.

## Script
- Reads `ELEVENLABS_API_KEY` from env (`process.loadEnvFile?.()` in try/catch); exits with a clear message if missing.
- For each effect, call the sound-generation endpoint (check the current ElevenLabs docs; at the time of writing it is `POST https://api.elevenlabs.io/v1/sound-generation` with `{ text, duration_seconds, prompt_influence }` and header `xi-api-key`), save the MP3. Skip files that already exist unless `--force`.
- Effects (keep them playful, never harsh; consistent loudness):

| file | prompt | seconds |
|---|---|---|
| tap.mp3 | soft rounded wooden UI tap, very short, clean | 0.5 (trim to the first 150ms if possible, else keep) |
| pop.mp3 | cheerful bubble pop, game UI | 0.5 |
| drumroll.mp3 | short snare drumroll building tension, game show, ends abruptly | 1.6 |
| slam.mp3 | punchy cartoon impact thump with a tiny sparkle | 0.6 |
| chaching.mp3 | cash register cha-ching with a bright sparkle, celebratory | 1.0 |
| buzzer.mp3 | friendly game-show wrong-answer buzzer, soft and short | 0.7 |

- Print each file's size when done.

## Acceptance
- [ ] Six files exist, sound good together, and are small (< 60 KB each where possible).
